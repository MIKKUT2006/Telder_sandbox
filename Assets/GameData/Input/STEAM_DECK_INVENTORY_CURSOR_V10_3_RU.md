# Telder — Steam Deck / Gamepad V10.3

Устанавливать **поверх V10.2**. Патч не изменяет JSON предметов и сохранений.

## Изменения

- Строительный прицел: блоки и инструменты (кирки, топоры и т. д.) используют голубую привязанную к сетке рамку. Проверяется `ItemType` и настоящее `Weapon.Kind`, а не просто наличие `Weapon` в JSON.
- `WeaponMetadataRegistry.IsWeapon` больше не помечает инструмент с `Weapon: { "Kind": "None" }` как оружие. Это также восстанавливает обычное копание RT, которое ранее блокировалось.
- Скорость строительного прицела по умолчанию увеличена с **5.3 до 12.5 блоков/с**; для старых настроек V10/V10.2 применится одноразовая миграция. В меню «Общие» диапазон увеличен до 32 блоков/с, шаг — 2.5.
- При открытии инвентаря появляется **фокус на первой ячейке хранилища**. Ячейку можно выбрать левым или правым стиком / крестовиной, повторное перемещение ускорено. Блок слота подсвечивается.
- Предмет, взятый виртуальным курсором инвентаря, следует за выбранным слотом, а не за неподвижной аппаратной мышью. При закрытии инвентаря возвращается обычный прицел мира.
- Окна печи, сундука, Tool Bench и обычные кнопки продолжают использовать тот же механизм фокуса и кликов. Сканирование Canvas ограничено по частоте.
- Навигация по UI не выключается, если в настройках выключен игровой прицел (при подключённом геймпаде).

## Кнопки в интерфейсе

| Кнопка | Действие |
| --- | --- |
| Левый/правый стик, D-Pad | Выбрать ячейку, кнопку или вкладку |
| A | Взять / положить стак, нажать кнопку |
| X | Быстро переместить предмет (включая печь и сундук) |
| L3 | Разделить стак / положить по одному (ПКМ-эквивалент) |
| B | Назад / закрыть инвентарь |
| Y | Открыть / закрыть инвентарь |

Пользовательские назначения в «Управление → Геймпад» сохраняются. При работе с клавиатурой/мышью обычные действия остаются прежними.

## Установка

Распакуйте hotfix в `Assets/` **с сохранением дерева папок**. Изменены четыре C# файла:

- `GameData/Input/GameInput.cs`
- `GameData/Input/GamepadUIFocusDriver.cs`
- `GameData/Combat/WeaponMetadataRegistry.cs`
- `GameData/UI/Settings/SettingsTabsController.cs`

В Unity остановите Play Mode и запустите заново. Для Gamepad.current используется установленный Unity Input System (`Active Input Handling = Both`).

## Быстрая проверка

1. Возьмите `iron_pickaxe` (в нём есть `Weapon.Kind = None`), подойдите к камню, проверьте голубую рамку и копание через RT.
2. Возьмите блок камня — должна остаться голубая рамка, LT ставит блок.
3. Возьмите настоящий меч `Weapon.Kind = Sword` — должен включиться оранжевый боевой прицел.
4. Нажмите Y: появится выделение ячейки инвентаря, при A предмет переходит на виртуальный курсор и следует за выбранной ячейкой, при повторном A кладётся.
5. Проверьте X с открытой печью и сундуком, L3 для разделения, B для закрытия.

## Ограничения проверки

Патч проверен статически и по содержимому архива, но не проходил компиляцию/Play Mode в редакторе Unity и тест на настоящем Steam Deck в этой среде.
