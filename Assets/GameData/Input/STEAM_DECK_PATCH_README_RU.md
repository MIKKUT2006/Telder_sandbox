# Telder Gamepad / Steam Deck / Settings Patch V10

## Установка

Это hotfix: скопируй содержимое архива `GameData/` в существующую папку
`Assets/GameData/` с заменой одноимённых файлов. Сцены, префабы, ресурспаки,
миры, сохранения и JSON предметов этот патч не заменяет.

**Важно для настоящих аналоговых стиков и LT/RT Steam Deck:**
1. Открой Unity > `Tools/Game/Steam Deck/Install Unity Input System`.
   Если `Input System` уже установлен, пропусти этот пункт.
2. В Unity > Project Settings > Player > Other Settings > Active Input Handling
   выбери **Both**. Это обязательно, потому что в существующей GameData есть
   классы, использующие старый UnityEngine.Input.
3. Перезапусти Unity по запросу. Протестируй Play Mode с подключённым геймпадом.
4. Steam Input: рекомендуемый шаблон **Gamepad**, не «Keyboard and Mouse».

Если пакет Input System не установлен, клавиатура/мышь сохранят работу, а
часть кнопок старого XInput доступна через JoystickButton. Аналоговые триггеры,
полноценный правый стик и детект геймпада из нового Input System требуют пунктов выше.

## Управление по умолчанию (Steam Deck)

| Управление | Действие |
|---|---|
| Левый стик | ходьба; вверх/вниз/в стороны в интерфейсе |
| Правый стик | 2D — виртуальный прицел; 3D — камера |
| A | прыжок; подтвердить в UI |
| B | назад, закрыть окно; в паузе — продолжить |
| X | взаимодействие; быстрый перенос предмета в UI |
| Y | инвентарь; создание мира из меню планет |
| RT | атака / копание |
| LT | установка / использование |
| RB / LB | следующий / предыдущий слот хотбара; в настройках — вкладки |
| Start | пауза |
| правый стик (нажатие) | выбросить предмет |
| левый стик (нажатие) | разделить стак в UI |
| D-Pad | навигация интерфейса; режим поворота / смены слоя |
| Select / View | окно измерений (если контекст портала доступен) |

В меню сохранений **LB/RB** переключают планеты, **A** загружает выбранный мир,
**X** открывает контекстное меню, **Y** создаёт мир, **B** возвращает назад.
В интерфейсе инвентаря/печи/сундука/Tool Bench фокус отображается рамкой;
**A** переносит стак курсором, **X** быстро переносит, нажатие левого стика
разделяет стак. Правый стик в 2D двигает игровой прицел относительно экрана.

## Настройки

И в паузе, и в главном меню пункт `Настройки` теперь открывает одно окно:
- **Общие:** громкость, вибрация (флаг для дальнейшего использования в эффектах),
  мёртвая зона и скорость прицела.
- **Графика:** оконный / без рамок / эксклюзивный полный экран; низкая / средняя /
  высокая детализация. Для существующего ChunkRenderer она меняет Point/Bilinear
  фильтрацию освещения и предел обновления световых текстур: 2/4/6 чанков за проход.
- **Управление:** вложенные вкладки «Клавиатура» / «Геймпад», список действий
  в двух колонках, две страницы, назначение кнопки, сброс раскладки.

Для переназначения выбери строку и нажми новую клавишу или кнопку геймпада.
На клавиатуре Esc отменяет назначение. Изменения сохраняются сразу в PlayerPrefs
с ключом `TELDER_CONTROLS_V1` и действуют для всех миров.

## Что подключено

- Движение/прыжки/лестницы и плавание через общее действие Jump.
- Копание/размещение, оружие, печь, сундук, верстак, Tool Bench, multiblock,
  повороты блоков, режим слоя, хотбар и 3D voxel-controller.
- Управление Unity UI кнопками и собственными слотами с видимым фокусом.
- Главное меню, планеты сохранений, настройки, пауза, экран смерти, инвентарь,
  печь, сундуки, крафт с UI-кнопками, Tool Bench и посещённые измерения.
- Программа не перезаписывает JSON игры и не требует ручных изменений сцен.

## Ограничения

- Не проведён Unity Play Mode / физический тест Steam Deck в этой среде.
- Аналоговые стики как физические оси по умолчанию фиксированы; цифровые действия,
  кнопки и D-Pad можно переназначать. Для сложных макросов используют Steam Input.
- В старом меню измерений используется IMGUI: на геймпаде выбираются посещённые
  измерения крестовиной/левым стиком и подтверждаются A; имя нового измерения
  при необходимости вводится с экранной клавиатуры Steam Deck (STEAM+X).
- Вибрация хранится как настройка; игровые эффекты вибрации пока не связаны с ней.
- Темы UI программно используют существующий пиксельный шрифт паузы, если он есть;
  собственную текстуру панели можно назначить полям SettingsTabsController при
  дальнейшей интеграции с префабом/поставщиком темы.

## Быстрая проверка в Unity

1. Запусти мир с геймпадом: левый стик, A, RT, LT, правый стик, LB/RB.
2. Нажми Y: перейди между слотами, A возьми, X быстро переложи, B закрой.
3. Открой печь и сундук: попробуй перенести несколько стаков.
4. Открой паузу Start > Настройки > Управление и переназначь A/RT,
   проверь обе колонки и графику.
5. Открой главное меню: выбери планету через RB/LB, A — загрузка, X — контекст.
6. Сохрани, перезапусти Play Mode и проверь, что новые биндинги остались.

Если Unity выдаёт CSxxxx, приложи текст всех ошибок Console. Отдельные версии
Unity/Input System различаются, и без компиляции в конкретном проекте нельзя
обещать отсутствие интеграционных ошибок.
