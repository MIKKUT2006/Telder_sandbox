# Telder V10.2 — исправление невидимого прицела геймпада

Устанавливается ПОВЕРХ V10.1. Содержимое папки `GameData/` из архива скопировать в `Assets/GameData/`, с заменой одноимённых файлов.

## Исправления

1. При подключённом геймпаде игровой прицел активен постоянно (пока игра не на паузе и не открыт UI), а не только при перемещении правого стика. Движение эмулированной мыши больше не выключает его.
2. Отрисовка рамки/мишени перенесена в независимый от Canvas/EventSystem обработчик `OnGUI`. Графические файлы или префабы не нужны.
3. Проверка существования `MainMenuController` больше не скрывает прицел в игровой сцене при аддитивной загрузке.
4. Если `Camera.main` не найдена или не является 2D-камерой, выбирается доступная активная ортографическая камера.
5. При загрузке сцены сбрасываются устаревшие ссылки на игрока, камеру и меню.
6. Для профилей Steam Input, которые эмулируют мышь, добавлено управление курсором по смещениям эмулированной мыши, если физический `Gamepad.current` недоступен.

## Проверка

1. Полностью остановить Play Mode; скопировать hotfix; дождаться компиляции; запустить 2D мир.
2. Подключить геймпад. Прицел должен появиться справа от персонажа СРАЗУ — даже когда правый стик не двигается.
3. Правый стик: при инструменте/блоке голубая рамка 1 блока в радиусе 5 клеток; при оружии оранжевый прицел в фиксированном радиусе.
4. Если курсор всё ещё отсутствует, открыть Настройки → Общие и включить `Диагностика прицела`. При необходимости включить `Принудительный прицел`.
5. В верхнем левом углу игрового экрана появится диагностика: `AIM: ...`, `Device: ...`, `Right stick: ...`. Точный текст `AIM` поможет найти последнюю причину отключения.

## Если прицел виден, но стик его не двигает

`Device: Legacy joystick | Right stick: (0.00, 0.00)` означает, что Input System не видит аналоговое состояние правого стика. В Steam Input выберите раскладку «Gamepad» и проверьте установленный пакет `com.unity.inputsystem` (просто `Active Input Handling = Both` само по себе НЕ устанавливает пакет).

Если Steam Input использует режим эмуляции мыши, можно включить `Принудительный прицел`: смещения такой мыши будут использоваться для игрового прицеливания. Работоспособность зависит от выбранной Steam Input раскладки.

В 3D-измерениях отдельной рамки нет — там по-прежнему центральный прицел камеры.
