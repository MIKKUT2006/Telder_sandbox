# Telder V8 — Ladder / Door / Hatch

Добавлено универсальное поле блока:

```json
"Behavior": "Ladder"
```

Поддерживаются значения `Ladder`, `Door`, `Hatch` и `Trapdoor` без учёта регистра. Для совместимости также распознаются теги `ladder`, `door`, `hatch`.

## Лестница

Лестница не имеет коллизии. Игрок может пройти сквозь неё. Пока тело игрока касается лестницы:

- удерживание `Space` поднимает игрока;
- отпускание `Space` заставляет игрока медленно сползать вниз;
- обычное горизонтальное движение сохраняется;
- после выхода с лестницы снова действует обычная гравитация.

Лестница может находиться в foreground, background или Furniture/MultiBlock слое.

Пример блока находится в `Examples/ladder_block.json.txt`.

## Дверь / люк

Закрытая дверь использует обычную коллизию блока. ПКМ переключает состояние `open`.

В открытом состоянии:

- визуальная система использует `States -> State: open`;
- коллизия полностью отключается;
- через дверь/люк можно пройти;
- состояние сохраняется отдельно для каждого сохранения и измерения.

Повторный ПКМ закрывает объект и возвращает базовую текстуру. Если персонаж стоит внутри открытой двери, закрытие временно блокируется, чтобы игрок не застрял.

Для обычного foreground-блока state-текстуры кладутся в:

`Assets/GameData/ResourcePacks/Default/textures/blocks/`

Для MultiBlock/Furniture двери state-текстуры рекомендуется класть в:

`Assets/GameData/ResourcePacks/Default/textures/multiblocks/`

Пример двери 1x2: `Examples/door_1x2_block.json.txt`.
Пример люка 1x1: `Examples/hatch_block.json.txt`.

## Пример предмета

Как и у кровати, MultiBlock-двери нужен обычный item JSON с тем же ID, чтобы она появлялась в инвентаре и могла быть установлена. Пример: `Examples/door_item.json.txt`.

## Item JSON

Для каждого устанавливаемого блока нужен обычный item JSON с тем же `ID`. Готовые шаблоны лежат рядом: `ladder_item.json.txt`, `door_item.json.txt`, `hatch_item.json.txt`.
