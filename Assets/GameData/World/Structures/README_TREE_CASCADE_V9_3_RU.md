# Рубка деревьев V9.3

Система больше не уничтожает всё дерево синхронно за один кадр.

## Правило рубки

Если игрок сломал блок ствола на высоте Y:

- сам сломанный блок исчезает сразу;
- все клетки структуры ниже Y остаются — это пень;
- удаляется только связанная часть дерева на Y и выше;
- разрушение распространяется волной от места сруба вверх и в стороны;
- учитываются Foreground, Background и Furniture.

Связность считается по 8 соседям. Пустые/уже сломанные клетки не используются как мост, поэтому волна не перепрыгивает через разрыв в дереве.

## Оптимизация

1. План разрушения строится за O(N) по клеткам структуры через Dictionary + BFS. Старый вариант делал проход Height × Cells.
2. Разрушение распределено по кадрам. Один активный ствол разрушает примерно один следующий блок раз в 0.035 секунды.
3. На весь кадр действует общий бюджет MaxCellsPerFrame = 2, поэтому несколько одновременно падающих деревьев не создают большой пик.
4. Полная collision-сетка чанка не перестраивается после каждого блока. Изменённые чанки объединяются и обновляются максимум примерно раз в 0.12 секунды.
5. Furniture при каскаде не записывает save-файл и не перестраивает освещение после каждой ветки/листа. В конце волны save пишется один раз, а освещение обновляется по редкой сетке точек в пределах дерева.
6. Предметы и визуал каждого блока всё ещё появляются/исчезают поэтапно, поэтому эффект разрушения остаётся видимым.

## Скорость волны

Файл:

`Assets/GameData/World/Structures/StructureCascadeBreakRunner.cs`

Основные параметры:

```csharp
private const float CellInterval = 0.035f;
private const int MaxCellsPerFrame = 2;
private const float CollisionFlushInterval = 0.12f;
```

`CellInterval` — задержка между блоками одного дерева.

`MaxCellsPerFrame` — общий лимит разрушений всех деревьев за один кадр.

`CollisionFlushInterval` — как часто разрешено пакетно перестраивать collision чанков во время падения дерева.
