# GameData code review — 2026-09-30

## Исправлено
- Убран крайне дорогой reflection-scan всех assembly/type из `GameplayContextKey.Get()`; теперь используются прямые API `SaveGameRuntime` и `DimensionTravelRuntime`.
- `MultiBlockStore.FindCell()` переведён с линейного поиска по всем многоблочным объектам на O(1) индекс по занятым клеткам.
- Многоблочные объекты теперь автоматически очищают occupancy-запись, если anchor-furniture был сломан другим игровым кодом.
- Исправлен расчёт точки спавна кровати с учётом `Width/Height/AnchorX/AnchorY`.
- Если кровать не задана, respawn возвращает игрока на стандартную точку мира (X=0 над поверхностью), а не на место смерти.
- Death system теперь подписан на `PlayerStats.Died`, без reflection и polling каждый кадр.
- При смерти управление блокируется, время игры замораживается, курсор разблокируется; при respawn состояние корректно возвращается.
- Инвентарь не очищается, если `ItemDropSpawner` недоступен — это предотвращает безвозвратную потерю предметов.
- Полное восстановление здоровья/голода выполняется через реальный `PlayerStats.RestoreState()`.
- Furnace metadata теперь читается из уже загруженного `ItemRegistry`, а multiblock metadata — из `BlockRegistry`; удалены повторные обходы JSON-файлов.
- Печь больше не пишет save-файл каждую секунду независимо от изменений: добавлены dirty flag + пакетное сохранение раз в 5 секунд, save при закрытии/смене сцены/выходе.
- Save-файлы новых gameplay-систем пишутся через временный файл/replace для меньшего риска повреждения.
- Выход печи учитывает реальный `MaxStack` результата, а не hardcoded 100.
- Слоты печи умеют дозаполняться совместимым выбранным стаком; UI показывает Name предмета вместо ID.
- Добавлена блокировка взаимодействия с миром при открытом UI печи.
- Убраны бесконечные `Resources.FindObjectsOfTypeAll` polling-циклы для durability overlay и ToolBench bootstrap; установка делается в bootstrap-окне после загрузки сцены.
- Runtime UI кэширует Font, вместо повторного создания/поиска шрифта для каждого текста.

## Проверки
- 171 JSON-файл успешно разобран стандартным JSON parser: синтаксических ошибок нет.
- Для изменённых C# файлов проверен баланс блоков `{}`.
- Повторно просканированы runtime `Update/FixedUpdate/LateUpdate` на тяжёлые scene/resource scans; два наиболее дорогих постоянных polling-механизма устранены.

## Найдено, но не изменено автоматически
- Отсутствуют texture-файлы для `Items/teleportium_pickaxe.json` и `Items/iron_pickaxe.json` (а также для нескольких `_WeaponExamples`). Это контентная проблема: без исходного арта безопасно подменять текстуры нельзя.
- В проекте накоплено много backup/installer-файлов в `Editor/`. Они не участвуют в runtime, но увеличивают шум проекта. Их можно отдельно почистить после проверки, что старые installers больше не нужны.
- Полноценную Unity-компиляцию и PlayMode/Profiler-тест невозможно выполнить вне самого Unity Editor; после импорта рекомендуется один compile pass и короткий smoke-test: bed placement/break/respawn, furnace open/smelt/close/break, death with full inventory, dimension switch.
