# Furnace UI V3 — Inventory companion

## Что изменено

Печь больше не создаёт отдельное белое окно/Canvas.

При ПКМ по печи теперь:

1. Открывается обычный `InventoryUI`.
2. Компактная панель печи появляется **над `InventoryPanel`**.
3. В панели нет заголовка, подписей, процентов и кнопки закрытия.
4. Есть только:
   - input — переплавляемый предмет;
   - fuel — топливо;
   - output — результат;
   - маленькая шкала процесса переплавки без текста.
5. `E` закрывает обычный инвентарь и вместе с ним печь.
6. Печь после закрытия продолжает работать как раньше.

## Управление предметами

- ЛКМ — взять/положить/объединить стак так же, как в основном инвентаре.
- ПКМ — взять половину или положить один предмет.
- ПКМ с удержанием и наведением — раздача по одному по слотам печи.
- Shift + ЛКМ по предмету игрока:
  - переплавляемый предмет автоматически идёт в input;
  - топливо автоматически идёт в fuel;
  - неподходящий предмет использует обычный quick-move hotbar <-> storage.
- Shift + ЛКМ по любому слоту печи — быстрый перенос обратно в инвентарь.
- В output нельзя вручную класть предметы.

## Индикатор топлива

Во время горения вокруг fuel-слота уменьшается оранжевая рамка.

Если `Burn Border Sprite` не задан, рамка собирается автоматически из 4 линий.
Она исчезает по периметру: left -> top -> right -> bottom по мере окончания топлива.

Если назначить `Burn Border Sprite`, используется сама текстура рамки с radial fill.
Лучше всего подходит PNG, где видна только прозрачная рамка.

## Где менять текстуры, цвета и размеры

Выбери объект с компонентом `InventoryUI`.
В Inspector появился раздел:

`Furnace UI Appearance`

### Textures

- `Panel Sprite`
- `Input Slot Sprite`
- `Fuel Slot Sprite`
- `Output Slot Sprite`
- `Burn Border Sprite`
- `Smelt Progress Background Sprite`
- `Smelt Progress Fill Sprite`

Если текстура слота печи не назначена, используется `Storage Slot Sprite` основного инвентаря.

### Colors

Можно отдельно менять:

- цвет панели;
- input/fuel/output;
- обычную обводку;
- горящую обводку fuel;
- фон/заполнение шкалы переплавки;
- цвет количества предметов.

### Layout

Можно менять:

- размер панели;
- размер слотов;
- расстояние над основным инвентарём;
- общий offset панели;
- позиции input/fuel/output;
- позицию и размер smelt progress;
- толщину обычной/горящей рамки.

## Экран смерти

Старое белое окно смерти удалено.

Новый экран смерти берёт **реальную панель паузы как визуальный шаблон**:

- то же затемнение;
- та же правая компоновка;
- тот же pixel font;
- те же текстуры/цвета кнопок;
- те же hover/pressed-настройки `MenuButtonVisual`.

Отличается только содержимое:

- `ВЫ УМЕРЛИ`
- `ВОЗРОДИТЬСЯ`
- `В ГЛАВНОЕ МЕНЮ`

Если позже поменять внешний вид Pause UI, экран смерти автоматически подхватит этот стиль.
